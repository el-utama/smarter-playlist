Komponen anotasi tidak masuk dalam alur data - dipakai untuk menandai program agar mudah dibaca.

### comment

**Label UI:** `Comment` | **Output:** track | **Judul tampilan node:** `$text`

A comment node for annotating the graph

**Port input:**

Tidak ada input (sumber / bertanda parsial).

**Parameter:**

- **Text** - tipe: string. Comment text
- **Style** - tipe: string, default: `sticky`. Nilai: `sticky, simple, subtle`. Visual style
- **Color** - tipe: string, default: `yellow`. Nilai: `yellow, blue, green, pink, purple, gray`. Color theme
- **Size** - tipe: string, default: `medium`. Nilai: `tiny, small, medium, large`. Text size

**Dokumentasi resmi (help):**

This component is a no-op comment for annotating the program graph.
